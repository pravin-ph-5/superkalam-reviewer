SuperKalam Veteran Reviewer Console
Open index.html in Chrome/Edge.

Includes:
- Reviewer dashboard with tier and tiered rates
- Review queue for two weekly questions
- Handwritten-style answer sheet
- Collapsible rubric
- Demand, introduction, structure, analysis, examples/facts, conclusion, presentation and overall feedback
- Click highlighted answer text to show the exact reviewer comment that becomes visible to the aspirant
- Review submission and payout interaction
- Payments, SuperKalam feedback, aspirant feedback and reviewer profile
- Attached SuperKalam logo included locally

Note: the third-tier / internal near-miss classification is intentionally not exposed in the UI to reviewers or aspirants. This prototype shows only the reviewer-facing tier/rate.
